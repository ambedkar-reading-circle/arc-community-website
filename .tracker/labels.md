# Wayfinder Labels

| Label | Description | Type |
|-------|-------------|------|
| `wayfinder:map` | Canonical map issue — the index of decisions | Map |
| `wayfinder:research` | Research ticket — agent reads docs/apis to surface facts | AFK |
| `wayfinder:prototype` | Prototype ticket — make a rough artifact to react to | HITL |
| `wayfinder:grilling` | Grilling ticket — one question at a time conversation | HITL |
| `wayfinder:task` | Task ticket — manual work that unblocks a decision | HITL/AFK |
