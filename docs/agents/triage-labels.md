# Triage Labels

The five canonical triage roles, each label string equals its name:

| Label | Role |
|-------|------|
| `needs-triage` | New issue, not yet categorized |
| `needs-info` | Missing context, waiting for reporter |
| `ready-for-agent` | Specified, ready for AI implementation |
| `ready-for-human` | Specified, ready for human implementation |
| `wontfix` | Declined, no action planned |
